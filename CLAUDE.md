# nebo-rea

Repo di appoggio per usare REA (`LBNM-ONE/rea`) dalle sessioni cloud di Claude Code.

All'inizio di una sessione leggi `HANDOFF.md`: contiene obiettivo, stato e passi.
Gli script sono in `scripts/` (`setup-rea.sh` prepara REA, `get-apk.sh` scarica un
file da un link Google Drive). Non committare APK, JAR o altri binari.
